# Проверки перед передачей

- Чистая установка зависимостей из `package-lock.json` проверена в отдельной папке. npm audit: 0 известных уязвимостей на момент проверки.
- Production-сборка Next.js и строгая проверка TypeScript проходят.
- 14 автоматических тестов на PGlite (PostgreSQL), в том числе права ролей БД и повторное применение SQL.
- HTTP-проверки через настоящие обработчики Next.js: неверный админский пароль, запрет запросов с другого Origin, запрет админских операций участнику, приватность журнала, отказ при устаревшей ревизии, повторная запись без дубля.
- Восемь параллельных HTTP-запросов записи создают восемь разных последовательных мест. Использовалась изолированная локальная PostgreSQL-база; нагрузочный тест реального облачного Supabase не проводился.
- Через браузер проверены вход, создание и редактирование пары, самостоятельная запись, ручное добавление, перенос стрелкой и на конкретное место, обмен, отметка прошедшего, закрытие записи, завершение и просмотр истории.
- Интерфейс проверен при ширине 1280 и 390 пикселей. На мобильной ширине горизонтального переполнения не обнаружено. Ошибок в консоли браузера при проверке нет.
- Дополнительная проверка адаптивности охватила 20 размеров от 320 px до 4K, формы, историю и окна подтверждения. Найденные проблемы исправлены; подробности и ограничения проверки — в `RESPONSIVE.md`.
- Скриншот `interface.png` сделан на изолированной тестовой базе. Тестовые имена не встроены в приложение и не загружаются при подключении Supabase.

Реальный проект Supabase и Production-развёртывание Vercel подключает владелец по README. Их проверка требует его настроек и ключей и в эти локальные проверки не входит.
